# PRIMA

**One line:** The sketchpad experience layer — takes hotel candidates from SHERPA and renders them as interactive visual cards in FORK, SWATCH, SWIPER, or COMMIT mode.

## What it does
- Defines all shared data types for the sketchpad: SketchFrame, SketchCard, HotelBlock, AnchorBlock, RenderMode
- Provides the pattern catalogue — templates that define how many sketches to show and on which variation axis
- Validates sketches against hard travel constraints via the Reality Lattice before showing them
- Anchors library: curated POIs (409 Rome + Paris landmarks) linked to hotels by distance
- Admin UI: 6 panels in AgentSetupDashboard to manage patterns, anchors, lattice rules, and cities

## Where the code lives
PRIMA is not a separate repo — its logic is split across:
- **SHERPA repo** (`mywai-sherpa`): all type definitions, pattern catalogue, lattice, render policy, sketch engine
- **PRIMA admin UI** (`mywai-hotel-providers`): `ui/src/components/AgentSetupDashboard.tsx` and `AgentPlayground.tsx`

## Logical flow (sketch rendering)
1. `sketch_engine.py` receives hotel candidates from DNA shortlist
2. Render Policy decides N (1/2/3/7 sketches) and variation axis
3. For each of N sketches, hotel is picked at a different axis value (e.g. luxe_threshold: -0.3, 0.0, +0.3)
4. Each sketch is lattice-checked — auto-fixes applied, user confirms surfaced
5. Copy (headline + body) generated by Sonnet per sketch
6. SketchFrame published to AppSync; client renders mode-appropriate layout

## Critical code
```python
# sketch_types.py — RenderMode enum
class RenderMode(str, Enum):
    COMMIT = "commit"   # 1 sketch — accept or refine
    FORK   = "fork"     # 2 sketches — which direction?
    SWATCH = "swatch"   # 3 sketches — pick a vibe
    SWIPER = "swiper"   # 5-7 sketches — mobile swipe deck

# SketchFrame is the top-level object published to AppSync
class SketchFrame(BaseModel):
    mode: RenderMode
    sketches: list[SketchCard]   # 1, 2, 3, or 7 cards
    variation_axis: str          # which TasteField axis varies across sketches
    no_inventory: bool = False   # UI shows "no rooms found" state when True
    alternatives: list[HotelBlock] = []  # in-budget hotels not in primary set
```

## Gotchas
- Do not seed anchors for additional cities — Rome + Paris only until V2 is planned
- `no_inventory: True` on SketchFrame tells the UI to show "no rooms" — don't confuse with an empty `sketches` list (different UI states)
- V2 = origin-aware patterns (not started as of 2026-05-22)
